## 1. Header Requirements

- All rule files MUST include frontmatter header
- `description`: Clear explanation of the rule's purpose and scope
- `paths`: Array of file patterns where the rule applies (use glob patterns) if needed

## 2. Content Focus

- Only include requirements that need explicit emphasis or clarification
- Keep rules concise and maintainable for future updates
